Tài liệu REST API

Đường dẫn gốc: /api/v1 · Xác thực: header Authorization: Bearer <token> (hoặc tham số ?token=... cho luồng SSE). Định dạng phản hồi chuẩn: { "success": true, "data": ... } hoặc { "success": false, "error": "..." }.
Lưu ý đăng nhập: từ phiên bản 1.6.0, đăng nhập UI dùng tên đăng nhập + mật khẩu. Endpoint POST /auth/login trả về token phiên — gán vào header Bearer như mọi endpoint khác.
